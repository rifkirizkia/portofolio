Tentang Saya

Saya adalah seorang Mobile Developer dengan pengalaman lebih dari 3 tahun dalam pengembangan aplikasi mobile menggunakan Flutter dan React Native. Saya juga mampu untuk mendeploy aplikasi ke playstore dan appstore mau itu aplikasi baru ataupun pembaharuan aplikasi. Saya memiliki ketertarikan yang kuat pada UI/UX design dan DevOps, yang memungkinkan saya untuk menciptakan aplikasi yang tidak hanya fungsional tetapi juga menarik secara visual.

Latar belakang saya dalam pengembangan mobile dan minat pada DevOps memungkinkan saya untuk memahami siklus hidup pengembangan perangkat lunak secara menyeluruh, dari desain hingga deployment dan pemeliharaan.

Saya selalu bersemangat untuk belajar teknologi baru dan meningkatkan keterampilan saya. Saat ini, saya sedang memperdalam pengetahuan saya tentang praktik DevOps dan arsitektur cloud untuk meningkatkan efisiensi dan skalabilitas aplikasi yang saya kembangkan.
