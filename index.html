Tentang Saya

Saya adalah Software Engineer dengan pengalaman lebih dari 5 tahun dalam membangun aplikasi mobile, website, dan sistem backend yang siap digunakan di lingkungan produksi.

Saya membantu bisnis mengubah ide menjadi produk digital melalui proses end-to-end, mulai dari analisis kebutuhan, desain UI/UX, pengembangan aplikasi, hingga deployment ke server agar sistem dapat berjalan dengan stabil dan aman.

Selain pengembangan aplikasi menggunakan Flutter, React Native, dan teknologi web modern, saya juga berpengalaman dalam pengelolaan server, cloud, dan CI/CD untuk memastikan aplikasi siap digunakan dan mudah dikembangkan ke depannya.

Saya fokus membangun solusi yang cepat, aman, dan mudah digunakan untuk mendukung pertumbuhan bisnis klien.
